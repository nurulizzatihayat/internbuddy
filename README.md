# internbuddy
An internship tracker system that helps student manage application status, organize companies application and interviews.

## 🎯 Purpose

Applying for internships can get messy when you're keeping track of multiple companies, application deadlines, interviews, and follow-ups.

This tracker helps you:

* Keep track of internship opportunities
* Monitor application status
* Remember important deadlines
* Track interviews and assessments
* Store useful links and notes
* Compare opportunities in one place
* Keep a record of your overall internship search

## 📋 What to Track

Each internship entry can include information such as:

| Field                | Description                          |
| -------------------- | ------------------------------------ |
| **Company**          | Name of the company                  |
| **Position**         | Internship role/title                |
| **Department**       | Team or area you're applying for     |
| **Location**         | Internship location or remote status |
| **Application Date** | When you applied                     |
| **Deadline**         | Application deadline                 |
| **Status**           | Current stage of the application     |
| **Interview Date**   | Scheduled interview date             |
| **Contact**          | Recruiter or relevant contact        |
| **Link**             | Job posting or application link      |
| **Notes**            | Additional information               |

## 🔄 Application Status

Suggested statuses:

* 📝 **To Apply** — Opportunity saved but application hasn't been submitted
* 📤 **Applied** — Application submitted
* 👀 **Under Review** — Application is being reviewed
* 📞 **Interview** — Interview stage
* 🧪 **Assessment** — Completing a test, task, or assessment
* 🎉 **Offer** — Received an offer
* ❌ **Rejected** — Application unsuccessful
* 🚫 **Withdrawn** — Application withdrawn
* ⏸️ **On Hold** — Process temporarily paused

## ⭐ Priority

You can also assign a priority level to help decide where to focus your time:

* 🔴 **High** — Strong interest / important deadline
* 🟡 **Medium** — Interested, but not urgent
* 🟢 **Low** — Nice opportunity to have

## 📊 Useful Metrics

The tracker can also be used to monitor your progress, such as:

* Total applications
* Applications submitted
* Interviews received
* Offers received
* Rejections
* Applications awaiting a response
* Interview-to-application rate
* Offer-to-application rate

## 💡 Tips

* Update the tracker immediately after submitting an application.
* Record deadlines so you don't rely on memory.
* Keep notes after interviews while the conversation is still fresh.
* Save
